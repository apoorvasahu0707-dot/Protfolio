# Apoorva Sahu - Portfolio (React + Vite)

Run locally:
  npm install
  npm run dev        (opens http://localhost:5173)

Build for deploy:
  npm run build      (creates the dist folder)

Edit content: src/data.js  (name, links, projects, experience, skills)
Profile photo: src/assets/profile.jpg  (replace this file to change it)
Project screenshots: public/projects/  (replace the image, keep the same file name)
Live demo link for a project: src/data.js -> projects -> live: "https://..."
